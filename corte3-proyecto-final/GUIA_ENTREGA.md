# Guia de entrega - Corte 3

## Contenido del proyecto

- `parte1-sistema-turnos/`: mini proyecto funcional en Spring Boot, MySQL, HTML y Axios.
- `parte2-manual-web/`: landing page/manual web de estructuras de datos.
- `Formato_ABP.docx`: formato ABP diligenciado.
- `Formato_Excel_Informe.xlsx`: informe en Excel con resumen, pruebas, complejidad y plan ABP.
- `Proyecto_Estructura_Datos_Corte3_Completo.zip`: paquete comprimido con la entrega completa.

## Evidencias funcionales

1. Backend corriendo en `http://localhost:8080`.
2. Pantalla de `frontend/usuarios.html` con usuarios registrados.
3. Pantalla de `frontend/turnos.html` con turnos pendientes y un turno en atencion.
4. Pantalla de `frontend/cola.html` con estadisticas.
5. Pantalla de `parte2-manual-web/index.html`.
6. Resultado de `mvn test` para validar las pruebas del proyecto.

## Comandos principales

```bash
cd parte1-sistema-turnos
mvn spring-boot:run
mvn test
```

Base de datos:

```sql
SOURCE database.sql;
```
